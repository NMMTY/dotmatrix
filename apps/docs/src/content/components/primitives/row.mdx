`Flex` fixed to `direction: row`. The default horizontal layout primitive — reach for it whenever
children should sit side by side.

<CodeBlock
  codes={[
    {
      language: "tsx",
      code: '<Row gap="16" alignItems="center">\n  <Text>A</Text>\n  <Text>B</Text>\n</Row>',
    },
  ]}
  preview={
    <Row gap="16" alignItems="center">
      <Text>A</Text>
      <Text>B</Text>
    </Row>
  }
/>

## Examples

`wrap="wrap"` lets children flow onto additional lines instead of overflowing or shrinking to fit
— useful for a toolbar or tag list that shouldn't force a horizontal scrollbar on a narrow screen:

<CodeBlock
  codes={[
    {
      language: "tsx",
      code: '<Row gap="8" wrap="wrap">\n  {tags.map((tag) => (\n    <Chip key={tag}>{tag}</Chip>\n  ))}\n</Row>',
    },
  ]}
  preview={
    <Row gap="8" wrap="wrap" style={{ maxWidth: 200 }}>
      {["Design", "Engineering", "Product", "Marketing", "Sales"].map((tag) => (
        <Chip key={tag}>{tag}</Chip>
      ))}
    </Row>
  }
/>

`justifyContent="between"` is the common pattern for a header-style row — one group pinned to each
end with whatever space is left between them:

<CodeBlock
  codes={[
    {
      language: "tsx",
      code: '<Row justifyContent="between" alignItems="center">\n  <Heading as="h2">Section title</Heading>\n  <Button size="s">Action</Button>\n</Row>',
    },
  ]}
  preview={
    <Row justifyContent="between" alignItems="center" style={{ width: "100%" }}>
      <Heading as="h2" displaySize="xs">Section title</Heading>
      <Button size="s">Action</Button>
    </Row>
  }
/>
