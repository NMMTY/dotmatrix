A terminal-style prompt row: a `→` caret, one text field, and a footer for session context on the
left and key hints on the right. It is a single-line field that submits on Enter — for multi-line
or labelled form input use [Input](/components/forms/input) or [Textarea](/components/forms/textarea).

<Playground name="CommandInput" />

## Accessibility

There is no visible label, so `label` is required and becomes the field's accessible name. The `→`
glyph is decorative. Enter submits; Shift+Enter and IME composition do not.
