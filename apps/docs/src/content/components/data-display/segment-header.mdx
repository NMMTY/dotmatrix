A `[ ▪▪▪▪▪▪▪ ]` run of square segments. With every segment lit it is a section divider; with
`filled` below `segments` it doubles as a coarse progress readout — the same segmented look as
[Meter](/components/bitmap/meter), sized for a heading line instead of a gauge.

<Playground name="SegmentHeader" />

## Accessibility

Without `label` the whole header is decorative and hidden from assistive tech. Give it a `label`
and it becomes a `role="meter"` with `aria-valuenow`/`aria-valuemax` taken from `filled` and
`segments`.
