A `<th scope="col">` used inside [TableHead](/components/data-display/table-head).
`onSort`'s presence, not `sortDirection`, decides whether this renders as a button — a column can
be sortable but currently unsorted (`sortDirection` omitted or `"none"`), which still needs the
click target.

<Playground name="TableHeaderCell" />

## Examples

`sortDirection` mirrors `aria-sort` directly (`"ascending"`/`"descending"`/`"none"`) rather than a
custom enum — a non-sortable column simply omits both props:

<CodeBlock
  codes={[
    {
      language: "tsx",
      code: '<tr>\n  <TableHeaderCell sortDirection="ascending" onSort={() => sortBy("name")}>\n    Name\n  </TableHeaderCell>\n  <TableHeaderCell>Status</TableHeaderCell>\n</tr>',
    },
  ]}
  preview={
    <Table>
      <TableHead>
        <tr>
          <TableHeaderCell sortDirection="ascending">Name</TableHeaderCell>
          <TableHeaderCell>Status</TableHeaderCell>
        </tr>
      </TableHead>
      <TableBody>
        <TableRow>
          <TableCell>Ada Lovelace</TableCell>
          <TableCell>Active</TableCell>
        </TableRow>
      </TableBody>
    </Table>
  }
/>
