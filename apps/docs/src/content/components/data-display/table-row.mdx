A `<tr>` inside [TableBody](/components/data-display/table-body). Its `selected` prop highlights
the row and marks it `aria-selected` — row selection is opt-in per table, not a table-wide flag.

<Playground name="TableRow" />

## Examples

`selected` is the whole row-selection API — no separate checkbox column or selection context to
wire up, just a boolean per row:

<CodeBlock
  codes={[
    {
      language: "tsx",
      code: '<TableRow selected={selectedId === row.id} onClick={() => setSelectedId(row.id)}>\n  <TableCell>{row.name}</TableCell>\n</TableRow>',
    },
  ]}
  preview={
    <Table>
      <TableBody>
        <TableRow selected>
          <TableCell>Ada Lovelace</TableCell>
        </TableRow>
        <TableRow>
          <TableCell>Grace Hopper</TableCell>
        </TableRow>
      </TableBody>
    </Table>
  }
/>
