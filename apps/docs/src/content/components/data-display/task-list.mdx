An agent-style checklist: a summary line and one row per step, each with a pixel marker — a solid
square for the step in flight, a hollow one for steps not started, a check for done and a cross for
failed.

<Playground name="TaskList" />

## Accessibility

Status is never colour alone: every row carries its status as visually-hidden text ("Done:",
"In progress:", …) in front of the label, and `data-status` on the `<li>` for styling hooks.
