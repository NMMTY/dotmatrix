One component for any embeddable media — a plain image, a native `<video>`, or a YouTube/Vimeo
URL (swapped for its embed/no-cookie iframe form automatically, from the URL alone — no separate
`type` prop to set). Always renders into a fixed-aspect-ratio box, so surrounding content never
reflows once the media itself loads in.

Deliberately not run through [Dither](/components/bitmap/dither)/[Halftone](/components/bitmap/halftone):
this is for content that wants to look like an ordinary photo or video (a screenshot, a demo
recording), not this system's own bitmap aesthetic — reach for those instead when the point is
the dithered look itself.
