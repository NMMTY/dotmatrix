Stepped, frame-based effects at 15 fps (`--dm-fx-frame`, 67 ms — four frames of a 60 Hz display).
No easing: every state is a hard flip, like the dither grid. Each effect starts blank and ends as
the finished content; the sequences are read frame by frame off the reference field guide. `Fx`
renders its children untouched and restyles a wrapper layer (opacity, offset, scale, slices, a cell
mask, an outline); for `type` and `decode` a plain string child is rewritten step by step. Under
`prefers-reduced-motion` the effect is skipped and the content stays as it is.

## Effects

- `blinky` (4 steps) — grey, gone, full, grey.
- `glitch` (7) — the content is cut into slices that smear sideways, then a small jitter.
- `trail` (6) — a dim, wide smear that tightens onto the box as it brightens.
- `stroke-fill` (9) — a flickering outline, a half-tone fill, then solid.
- `shuffle` (6) — placeholder cross, warning, hatching; two steps each.
- `crash-blink` (5) — an oversized grey box, then on / off / on / grey.
- `slide-blink` (7) — settles upward from below while it blinks.
- `color-flash` (4) — tints the content with each of `palette` in turn.
- `build-on` (14) — a 4×4 cell mask that lights up cell by cell.
- `type` (6) — a string child typed out; `cursor` adds a block cursor.
- `decode` (6) — a string child resolves from noise, left → right.

`type` and `decode` need a string child. Any other child falls back to an untouched render.

## Triggers

`mount` (default), `in-view` (first time it scrolls into view), `hover`, `focus`, `exit` (when it
scrolls back out of view), `loop` (repeats forever) and `manual` — call `play()` on the ref.

## Timing

`frames` defaults to the effect's own length (listed above); another number resamples the sequence.
`fps` defaults to 15 (the examples above use 8 to read slower). `interval` rests on the finished content for that many milliseconds between repeats and `loop` plays. `delay` keeps the content blank for that many milliseconds before the first
step, and `stagger` offsets each direct child by one step (or by the number of milliseconds you
pass). `palette` is for `color-flash` and defaults to red, blue, green, purple. `repeat` takes a
count or `"infinite"`; `onDone` fires after the last step of the last repeat.
