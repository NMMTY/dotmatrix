The `role="tablist"` row of [Tab](/components/overlays/tab) buttons inside
[Tabs](/components/overlays/tabs) — requires an `aria-label` naming the tab group.

<Playground name="TabList" />

## Examples

`aria-label` should name the group of *content* being switched between, not the word "tabs"
itself — "Project sections", not "Tab list":

<CodeBlock
  codes={[
    {
      language: "tsx",
      code: '<TabList aria-label="Project sections">\n  <Tab value="overview">Overview</Tab>\n  <Tab value="activity">Activity</Tab>\n</TabList>',
    },
  ]}
  preview={
    <Tabs defaultValue="overview">
      <TabList aria-label="Project sections">
        <Tab value="overview">Overview</Tab>
        <Tab value="activity">Activity</Tab>
      </TabList>
      <TabPanel value="overview">Overview panel content.</TabPanel>
      <TabPanel value="activity">Activity panel content.</TabPanel>
    </Tabs>
  }
/>
